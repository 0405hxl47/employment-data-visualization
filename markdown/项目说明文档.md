# 高校毕业生就业数据分析平台 - 项目说明文档

## 一、项目概述

本项目是一个面向高校毕业生就业数据的可视化分析平台，采用前后端分离架构，提供多维度的就业数据统计、趋势分析和预警功能。平台覆盖 23 所高校、7 个毕业年份（2019-2025）共计 30,000+ 条就业记录，通过 20 种可视化图表帮助用户全面了解高校毕业生就业状况。

### 5.3 通用筛选参数

所有统计接口均支持以下查询参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| university_type | String | 院校层次 (985/211/双一流/普通本科等) |
| university_name | String | 高校名称 |
| degree | String | 学历层次 |
| graduation_year | Integer | 毕业年份 |
| keyword | String | 模糊搜索 (匹配专业名或高校名) |
| employment_type | String | 就业类型 (企业就业/升学/考公等) |
| industry | String | 行业 |
| province | String | 省份 |

> 前端全局筛选栏仅暴露前 5 个参数；后 3 个参数可通过直接调用 API 使用。

### 5.4 特殊接口参数

| 接口 | 参数 | 说明 |
|------|------|------|
| `/api/stats/salary_box` | group_by (默认 industry) | 分组维度：industry / degree / university_name |
| `/api/stats/major_analysis` | majorName (可选) | 按指定专业名过滤 |

### 5.5 就业率预警接口说明

`/api/stats/major_analysis` 返回的预警数据包含三个字段：

| 字段 | 说明 |
|------|------|
| `low_rate_count` | 就业率 < 60% 的学校-专业总数 |
| `low_rate_majors` | 就业率最低的前 5 条记录（用于图表默认展示） |
| `low_rate_all` | 完整列表（用于"查看完整列表"弹窗） |

该数据来自预计算的 `data/low_rate_majors.csv` 文件，按 `university_name + major_name` 分组，在后端启动时加载到内存缓存，不受全局筛选条件影响，始终展示全量预警数据。前端默认只渲染前 5 条以确保页面加载速度，用户可点击「查看完整列表」按钮在弹窗中查看全部预警专业。

### 5.6 就业趋势接口说明

`/api/stats/trend` 固定查询东北大学 2019-2023 年数据，不受全局筛选条件影响。数据来源为东北大学五年就业质量报告 Excel 文件，X 轴显示 5 个年份（2019-2023）。

## 七、数据来源说明

平台数据来自 23 所高校的就业质量年度报告，涵盖 7 个毕业年份：

| 年份 | 高校数 | 记录数 | 主要数据来源 |
|------|--------|--------|-------------|
| 2019 | 1 | 2,390 | 东北大学 |
| 2020 | 1 | 2,864 | 东北大学 |
| 2021 | 3 | 4,067 | 东北大学、哈尔滨工业大学、复旦大学 |
| 2022 | 4 | 2,145 | 东北大学、安徽大学、浙江大学、清华大学 |
| 2023 | 15 | 14,286 | 东北大学及其他 14 所高校 |
| 2024 | 1 | 645 | 郑州大学 |
| 2025 | 2 | 4,059 | 西安电子科技大学、青海大学 |
| **合计** | **23** | **30,456** | |

其中东北大学 2019-2023 五年完整数据来自五份就业质量报告 Excel 文件，为就业趋势分析的唯一数据源。

## 八、部署说明

### 环境要求
- JDK 8+
- Maven 3.6+
- MySQL 8.0+
- Node.js 16+
- npm 8+

### 方式一：一键启动（推荐）

1. **创建 MySQL 数据库**
```sql
CREATE DATABASE IF NOT EXISTS employment_db
DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

2. **确认数据库配置**

检查 `backend-springboot/src/main/resources/application.yml` 中的数据库连接信息（用户名、密码）。

3. **双击 `start_all.bat`**

脚本将自动完成以下步骤：
- 启动 SpringBoot 后端服务（端口 8081）
- 等待后端就绪（约 15 秒）
- 启动 Vue 前端开发服务器（端口 3000）
- 等待前端就绪（约 8 秒）
- 自动打开浏览器访问 `http://localhost:3000`

> 💡 启动后会打开两个终端窗口分别运行前后端服务，关闭对应窗口即可停止服务。

### 方式二：手动分步启动

1. **创建 MySQL 数据库**（同上）

2. **启动后端** (端口 8081)
```bash
cd project/backend-springboot
mvn spring-boot:run
```
首次启动自动从 CSV 文件导入数据。

3. **启动前端** (端口 3000)
```bash
cd project/frontend-vue
npm install
npm run dev
```

4. **访问平台**

浏览器打开 `http://localhost:3000`
