# 高校毕业生就业数据分析平台 - 使用操作手册

## 一、快速开始

### 1.1 环境准备

请确保已安装以下软件：

| 软件 | 版本要求 | 用途 |
|------|---------|------|
| JDK | 8 及以上 | 运行后端服务 |
| Maven | 3.6 及以上 | 构建后端项目 |
| MySQL | 8.0 及以上 | 存储就业数据 |
| Node.js | 16 及以上 | 运行前端开发服务器 |

### 1.2 创建数据库

打开 MySQL 客户端（如 Navicat、MySQL Workbench 或命令行），执行：

```sql
CREATE DATABASE IF NOT EXISTS employment_db
DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

### 1.3 配置数据库连接

打开 `backend-springboot/src/main/resources/application.yml`，确认数据库连接信息：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/employment_db?...
    username: root        # 修改为你的MySQL用户名
    password: 123456      # 修改为你的MySQL密码
```

### 1.4 一键启动（推荐）

完成数据库创建和配置后，**双击项目根目录下的 `start_all.bat`** 即可一键启动整个平台。

脚本会自动完成以下步骤：

```
[1/3] 启动 SpringBoot 后端服务（端口 8081）
      ↓ 等待 15 秒
[2/3] 启动 Vue 前端开发服务器（端口 3000）
      ↓ 等待 8 秒
[3/3] 自动打开浏览器访问 http://localhost:3000
```

> 💡 **注意事项：**
> - 首次启动时后端会自动导入 30,000+ 条 CSV 数据，约需 30 秒
> - 启动后会打开**两个终端窗口**分别运行前后端，关闭窗口即可停止服务
> - 如果电脑性能较慢，可在 `start_all.bat` 中调大 `timeout` 的等待秒数
> - 首次运行前端前需先执行 `npm install`（仅一次）

### 1.5 手动分步启动

如需手动控制启动过程：

**启动后端：**
```bash
cd project/backend-springboot
mvn spring-boot:run
```

**启动前端（新开终端）：**
```bash
cd project/frontend-vue
npm install          # 仅首次运行时需要
npm run dev
```

**访问平台：** 浏览器打开 **http://localhost:3000**

## 二、页面导航

平台包含 5 个主页面，通过顶部导航栏切换：

```
┌───────────────────────────────────────────────────────────────┐
│  高校毕业生就业数据分析平台                                      │
│  [首页总览] [行业与岗位分析] [专业分析] [地域流向分析] [薪资与深造分析] │
├───────────────────────────────────────────────────────────────┤
│  首页 / 当前页面名称                                 ← 面包屑导航  │
│  [院校层次▼] [高校名称▼] [学历层次▼] [毕业年份▼] [搜索框] [导出] [重置] │
├───────────────────────────────────────────────────────────────┤
│                        页面内容区域                             │
│                    (图表 + 数据表格)                            │
└───────────────────────────────────────────────────────────────┘
```

- **当前页面** 在导航栏中以黄色下划线高亮显示
- **面包屑导航** 显示当前位置，点击"首页"可快速返回首页总览

## 三、全局筛选功能

筛选栏位于导航栏下方，包含 5 个筛选条件：

### 3.1 筛选条件说明

| 筛选项 | 说明 | 示例 |
|--------|------|------|
| 院校层次 | 按学校等级筛选 | 985、211、双一流、普通本科、民办本科、高职 |
| 高校名称 | 选择具体学校 | 东北大学、清华大学 等（支持搜索输入） |
| 学历层次 | 按学历筛选 | 博士、硕士、本科、专科 |
| 毕业年份 | 按毕业届别筛选 | 2019届、2020届 ... 2025届 |
| 关键词搜索 | 模糊匹配专业名或高校名 | 输入"计算机"可筛选所有含该关键词的专业 |

### 3.2 联动筛选

- 选择"院校层次"后，"高校名称"下拉框会自动过滤，只显示对应层次的高校
- 选择"双一流"会同时展示 985 和 211 高校
- 所有筛选条件**实时联动**，修改任一筛选项，所有图表自动更新

### 3.3 重置筛选

点击 **重置筛选** 按钮，清空所有筛选条件，恢复显示全部数据。

## 四、数据导出

### 4.1 导出 Excel

1. 设置想要的筛选条件（或不设置任何条件导出全部数据）
2. 点击筛选栏右侧的 **导出 Excel** 按钮
3. 浏览器将自动下载 `就业数据.xlsx` 文件
4. 导出成功后会显示绿色提示"导出成功"

导出的 Excel 文件包含以下列：ID、学校名称、毕业年份、专业名称、学历、就业率、就业类型、行业、省份、城市、最低薪资、最高薪资、平均薪资、真实薪资、达成率、数据来源、学校类型。

## 五、各页面功能详解

### 5.1 首页总览

#### 统计卡片

页面顶部展示 5 项核心指标：

| 卡片 | 含义 |
|------|------|
| 数据总量 | 数据库中就业记录总条数 |
| 覆盖高校 | 涉及的高校数量 |
| 专业数量 | 涉及的专业数量 |
| 平均实际薪资 | 所有有薪资记录的平均实际月薪 |
| 平均就业率 | 去重后各专业平均就业率 |

#### 就业类型分布 (环形饼图)

展示各就业去向的占比：企业就业、升学、出国留学、考公、灵活就业、待就业、高校/科研。

**交互操作：**
- 鼠标悬停：显示具体数值和占比
- 图例点击：隐藏/显示对应类别

#### 行业就业人数占比 (矩形树图)

用面积大小直观展示各行业的就业人数。面积越大，该行业吸纳就业人数越多。

#### 三级流向桑基图

展示 **学历 → 就业类型 → 行业** 的多层流向关系。

**交互操作：**
- 鼠标悬停于连线：高亮显示该流向路径及人数
- 可观察不同学历的就业去向差异

#### 就业趋势变化 (双轴折线图)

展示东北大学 2019-2023 年就业趋势，包含两条折线：
- **蓝色线（左轴）**：各年度平均实际薪资（元/月）
- **红色线（右轴）**：各年度平均就业率（%）

数据来源为东北大学五年就业质量报告 Excel 文件，X 轴显示 5 个年份（2019-2023 届）。

**交互操作：**
- 鼠标悬停：显示该年度薪资、就业率和数据量
- 图例点击：隐藏/显示单条折线

#### 就业数据明细表格

展示前 10 条就业记录的详细信息。就业率低于 60% 的行会以**红色背景**高亮标记。

### 5.2 行业与岗位分析

#### 行业就业人数排名 (横向柱状图)

按就业人数从多到少排列各行业。

#### 行业平均薪资排名 (横向柱状图)

按平均薪资从高到低排列各行业，以"¥"标注薪资数值。

#### 旭日图

三层同心圆展示 **学历 → 就业类型 → 行业** 的层次结构。
- 内圈：学历层次
- 中圈：就业类型
- 外圈：具体行业

**交互操作：** 点击某一层可向内钻取/聚焦。

#### 专业关键词云

以词云形式展示高频专业名称，字号越大表示该专业就业人数越多。

### 5.3 专业分析

#### 就业率预警

页面顶部显示橙色警告横幅：

> ⚠️ 就业率预警：共有 XX 个专业就业率低于 60%，需重点关注

下方展示**预警专业柱状图**（默认展示就业率最低的前 5 条）：
- 横向柱状图展示就业率最低的 5 个学校-专业组合
- 柱状条按就业率从低到高排列
- Y 轴标签格式为「学校名 - 专业名」
- 颜色深浅表示严重程度：< 40% 深红，40-50% 红色，50-60% 橙色
- 红色虚线标注 **60% 警戒线**
- 每个柱状条右侧标注具体就业率数值

#### 查看完整列表

当预警专业超过 5 个时，柱状图下方显示**「查看完整列表」按钮**。点击后弹出对话框，以表格形式展示全部预警专业，包含排名、学校、专业、平均就业率和数据量，支持滚动浏览。

#### 行业分布玫瑰图 (南丁格尔玫瑰图)

以花瓣面积展示不同行业的就业分布，面积越大占比越高。

#### 专业薪资排名 (横向柱状图)

按平均薪资排列各专业。

**交互操作：** 鼠标悬停显示最低/最高薪资和样本数。

#### 热门就业城市 Top 10

以表格形式展示就业人数最多的前 10 个城市，包含排名、城市名、所属省份、就业人数和平均薪资。前 3 名以红色标签突出显示。

## 六、常见问题

### Q1：启动后端报错 "Communications link failure"
**原因：** MySQL 服务未启动或连接信息不正确。
**解决：** 确认 MySQL 正在运行，检查 `application.yml` 中的 `url`、`username`、`password` 是否正确。

### Q2：前端页面空白，无图表
**原因：** 后端服务未启动或端口不匹配。
**解决：** 确认后端已在 8081 端口运行，前端 `vite.config.js` 中代理指向 `http://localhost:8081`。

### Q3：地图不显示
**原因：** `china.json` 文件缺失。
**解决：** 确认 `frontend-vue/public/data/china.json` 文件存在。

### Q4：导出的 Excel 文件为空
**原因：** 当前筛选条件下没有匹配数据。
**解决：** 放宽筛选条件或点击"重置筛选"后重试。

### Q5：首次启动数据导入很慢
**原因：** 30,000+ 条数据需要逐批写入 MySQL。
**解决：** 耐心等待约 30 秒，控制台会显示导入进度。后续启动会自动跳过导入。

### Q6：一键启动脚本启动后浏览器打开白屏
**原因：** 电脑性能较慢，前后端尚未完全启动。
**解决：** 等待几秒后刷新页面。如仍不行，可修改 `start_all.bat` 中的 `timeout` 数值，将等待时间调大（如 `/t 25`）。

### Q7：如何停止服务？
**解决：** 关闭一键启动打开的两个终端窗口（标题分别为"后端服务"和"前端服务"）即可停止前后端服务。
